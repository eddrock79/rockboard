# Home Ritual artwork

- `cathedral.svg`: original cathedral, rose-window, candle and skull-mitre linework created for this home jukebox.
- `ghost-wordmark.webp`: Ghost's wordmark, downloaded from the band's official website for this personal home-use theme. Source: https://ghost-official.com/wp-content/uploads/2025/10/ghost-logo-updated-1.webp (https://ghost-official.com/). The wordmark belongs to its respective rights holders. This is an unofficial fan-made jukebox theme.

Assets are served locally with the jukebox. There are no third-party image requests during use.
